# Hardware

Phone holder for a VESA-mounted monitor, so the phone rotates together with
the screen (the @90 trick in the README depends on it).

- MonitorFlipBody.stl - body, screws to the VESA pattern
- MonitorFlipSlide.stl - sliding clamp for the phone

Designed for Galaxy A52s + Elo 1502L. Print details and photos to be added.
